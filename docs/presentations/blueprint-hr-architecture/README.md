# BluePrint HR Architecture, CI/CD, and Deployment Presentation

This directory contains the source outline and generated HTML slide project for the BluePrint HR architecture presentation.

The deck summarizes the implemented ASP.NET Core, SQL Server, React, and SSRS stack; the GitHub Actions validation and release workflows; the GHCR image publication flow; the protected Docker-host deployment path; and the operational controls for migrations, SSRS, secrets, health checks, and rollback.

The presentation was generated as an HTML slide project. The authoritative implementation and operational guidance remain in the repository root, `docs/CICD_SETUP.md`, `docs/DEPLOYMENT_RUNBOOK.md`, `docs/SSRS-CICD.md`, and `docs/RELEASE_CHECKLIST.md`.
