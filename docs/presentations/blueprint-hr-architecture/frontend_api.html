04 / Frontend integration

Same-origin locally, explicit origins in production

The React client has one API contract that works through a Vite proxy in development and an absolute API origin in production.

Local Development
Browser :5173
Vite proxy /api
ASP.NET Core :5000
Production Deployment
Browser HTTPS
CORS + secure cookie
API HTTPS
Private route
SQL Server / SSRS

Environment-based routing

VITE_API_URL is empty locally so Vite proxies /api/* and /health. In production, VITE_API_URL=https://api.example.com is embedded into the React build.

Cookie sessions

API requests use credentials: include to maintain the ASP.NET Core authentication cookie across both same-origin and cross-origin boundaries.

Cross-origin security

Separate production origins require explicit CORS origins, SameSite=None, Secure, and HTTPS to be configured on the API.

Credential isolation

The browser receives no SQL Server or SSRS passwords. All protected service communication originates from the backend API.
