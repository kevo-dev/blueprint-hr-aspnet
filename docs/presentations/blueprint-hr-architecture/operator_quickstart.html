Appendix / Quick Start

First release in eight commands

git checkout main
git pull --ff-only origin main
git tag -a v1.0.0 -m "BluePrint HR 1.0.0"
git push origin v1.0.0

# Review Publish container images in GitHub Actions
# Apply the approved database/Release.sql to SQL Server
# Dispatch Deploy to Docker VM with image_tag=v1.0.0
# Verify https://app.example.com/health
1. Tag the release
Creates an immutable marker on the validated main branch.
2. Publish images
GitHub Actions automatically builds and pushes to GHCR.
3. Migrate database
Apply the CI-generated SQL script to SQL Server.
4. Deploy & Verify
Approve the production environment gate and check the health endpoint.
Note: Exact secrets, environment setup, host preparation, migration procedures, SSRS deployment choices, and rollback steps are documented in the repository's docs/ directory.
